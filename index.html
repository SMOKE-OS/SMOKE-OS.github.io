Installation & Testing

Get Running in Minutes

Choose how you want to experience SMOKE OS: test safely in a virtual machine, flash to a USB stick, or build from scratch.

Launch the live ISO directly with KVM hardware acceleration. No installation or disk partitioning required:

qemu-system-x86_64 -enable-kvm -m 4G -smp 2 -cdrom Smoke_os_*.iso -vga virtio -display sdl,gl=on

• RAM: 4GB allocated to the VM (min 2GB required).

• Display: OpenGL enabled with virtio for full Wayland GPU acceleration.

Write the downloaded ISO image to a USB flash drive (replace /dev/sdX with your USB drive identifier):

sudo dd bs=4M if=Smoke_os_*.iso of=/dev/sdX status=progress oflag=sync

Alternatively, use Ventoy or Rufus (DD mode) on Windows.

Clone the smoke-iso repository on an Arch Linux machine and compile natively:

git clone https://github.com/SMOKE-OS/smoke-iso.git && cd smoke-iso && sudo mkarchiso -v -w /tmp/archiso-work -o ./out .

Common Questions

Frequently Asked Questions

What makes SMOKE OS different from vanilla Arch Linux? ↓

SMOKE OS comes with a meticulously configured Hyprland Wayland environment, Kitty terminal, Quickshell launcher, custom Plymouth splash, and unified Catppuccin Mocha / Smoke Dark color palette out-of-the-box. It saves hours of manual tiling window manager configuration while retaining 100% Arch compatibility.

Does SMOKE OS work with NVIDIA graphics cards? ↓

Yes, Hyprland supports NVIDIA hardware with proprietary drivers (nvidia-dkms). We recommend setting the required environment variables (LIBVA_DRIVER_NAME=nvidia and GBM_BACKEND=nvidia-drm) as documented in our configuration guides.

Can I try SMOKE OS configs on my existing Arch install? ↓

Yes! Check out our smoke-configs repository. It includes an interactive install.sh script that backs up your current dotfiles before installing the SMOKE OS desktop configuration.

How do I report bugs or submit feature requests? ↓

Please open an issue on the relevant repository under our GitHub Organization (e.g. smoke-iso for build issues, or smoke-configs for dotfile and keybinding improvements).
